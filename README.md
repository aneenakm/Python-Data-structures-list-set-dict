# Python – Data Structures and Conditional Statements

## Overview

This repository contains my second Python programming assignment, focusing on fundamental data structures, their operations, and conditional logic. The exercises demonstrate practical implementation of Python lists, dictionaries, sets, and decision-making statements.

## Topics Covered

### 1. Lists
- Creating lists of integers and strings
- Adding elements using `append()` and `insert()`
- Removing elements using `remove()` and `pop()`
- Extending lists using `extend()`
- Sorting elements in descending order
- Finding maximum, minimum, and sum
- Accessing elements using indexing and slicing
- Reversing list elements

### 2. Dictionaries
- Creating key-value pairs
- Accessing values using keys
- Adding new entries and updating existing values
- Retrieving keys, values, and items using built-in methods

### 3. Sets
- Creating sets and understanding duplicate removal
- Understanding why sets do not support indexing or item assignment
- Performing union and intersection operations

### 4. Conditional Statements
- Using `if`, `elif`, and `else`
- Evaluating score ranges
- Classifying performance into Above Average, Average, and Below Average
- Displaying appropriate messages based on conditions

## Technologies Used

- **Language:** Python
- **Concepts:** Data Structures, Operators, Conditional Statements
- **Tools:** Jupyter Notebook

## Learning Outcomes

- Understand how Python lists, dictionaries, and sets store and manipulate data.
- Apply built-in methods to perform common data operations.
- Understand indexing, slicing, and set behavior.
- Implement decision-making logic using conditional statements.
- Strengthen Python programming fundamentals through hands-on practice.
